# Fintrack - Frontend

Frontend oficial do Fintrack, feito com Vite + React + TypeScript.

## Scripts

```bash
npm install
npm run dev    # http://localhost:5173
npm run build  # build de producao em dist/
npm run lint
```

A API precisa estar rodando em `http://127.0.0.1:8000` (ou defina `VITE_API_URL` em um arquivo `.env`, usando `.env.example` como base).
